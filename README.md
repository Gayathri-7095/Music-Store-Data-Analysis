# Music Store Data Analysis

## Project Overview

This project focuses on analyzing music store data using SQL and data analytics techniques to uncover valuable business insights. The analysis helps understand customer behavior, sales performance, popular music genres, top-selling artists, and revenue trends.

By querying and analyzing music store data, the project demonstrates how SQL can be used to solve real-world business problems and support data-driven decision-making in the retail and entertainment industries.

---

## Objective

The primary objective of this project is to analyze music store data and generate meaningful insights that can help improve business performance and customer engagement.

The project aims to:

- Analyze customer purchasing behavior
- Identify top-selling artists and tracks
- Determine revenue-generating countries and cities
- Discover popular music genres
- Support business decision-making through data analysis

---

## Dataset

The project uses a Music Store database containing information about customers, invoices, tracks, albums, artists, genres, and employees.

### Database Tables

| Table | Description |
|---------|-------------|
| Customers | Customer information |
| Invoices | Purchase transactions |
| Invoice_Items | Details of purchased tracks |
| Tracks | Music track information |
| Albums | Album details |
| Artists | Artist information |
| Genres | Music genres |
| Employees | Employee records |
| Playlists | Playlist information |
